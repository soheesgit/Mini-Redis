상품 등록하기

상품 코드는 영문 소문자와 숫자를 쓰고 하이픈으로 연결할 수 있어요. 같은 코드로 다시 등록하면 판매 시간이 새로 시작돼요.

등록된 상품

편의점 예제 상품을 60초 동안 판매 목록에 올려요.

등록한 상품은 이 브라우저에 표시돼요. 상품을 선택하고 판매 상태를 확인하면 만료 여부를 알 수 있어요.
