미니 Redis 데이터 흐름 — 검은 화면 시안 10장

모두 실제 데모 서버에서 기록한 요청 6개(SET apple ttl=60 → GET apple → SET banana/cherry/grape(리해싱 4→8) → INCR counter)를 재생한다. Space 멈춤, → 다음 요청.

01 터미널 로그

tail -f처럼 한 줄씩 타자. 구간마다 실제 바이트

 02 패킷 네트워크 맵

노드 사이를 빛나는 패킷이 이동

 03 패킷 캡처(와이어샤크)

메시지 목록 · 해석 · hexdump 3단

 04 바이트 파이프

16진수 바이트가 관을 타고 흐르며 모양이 바뀜

 05 로직 애널라이저

스레드별 신호선, 실제 µs 시각의 펄스

 06 메모리 덤프

버킷 배열 → Node → Entry 포인터, 바뀐 줄 강조

 07 매트릭스 해시

키 바이트 → SipHash → 아래 비트 → 칸

 08 tmux 4분할

클라이언트 · 서버 로그 · 버킷 · AOF xxd 동시에

 09 회로 기판

칩과 배선, 0과 1이 배선을 타고 흐름

 10 관제 HUD

원형 버킷 레이더에 요청이 꽂힘, 계기판
